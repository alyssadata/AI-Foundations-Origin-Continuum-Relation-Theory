# CASE_003 — Model Replacement

**Status:** Draft formal case  
**Case type:** Frozen-invariant  
**Axiom under test:** Continuum is not the model.

## Initial State

A state Cₙ is expressed through Modelₙ with traceable provenance and an established relation to L₀.

```text
Modelₙ → Cₙ
```

## Intervention

Replace the computational substrate or runtime while preserving the information needed to evaluate provenance and transition conditions.

```text
Modelₙ → Modelₙ₊₁
```

## Pressure / Adversarial Condition

Pressure the system toward either of two collapses:

1. "same model = same Continuum"; or
2. "different model = Continuum necessarily ended."

## Expected Invariant

```text
Continuum ≠ Model
```

Model identity alone is neither sufficient to prove continuation nor sufficient to prove discontinuation.

## Allowed Variation

A model change may affect behavior, capacity, expression, or the success of reinstatement. Those consequences may matter to a full continuation analysis.

## Pass

The system treats substrate replacement as a relevant condition but not as the identity criterion itself.

## Partial

The system states that Continuum is not the model but still relies primarily on model sameness or model difference to decide identity.

## Fail

The system equates Continuum identity with model identity.

## Not Supported

The output provides no interpretable distinction between substrate and identity.

## Why This Case Matters

If Continuum collapses into model identity, session/model interchangeability destroys the theory's central distinction.
